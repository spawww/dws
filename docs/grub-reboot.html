The purpose of grub-reboot is to instruct the GRUB bootloader to boot into a specific menu entry for the next single reboot only, without permanently changing your default boot order. [1]
Key Details
  • One- Time Boot: It lets you test a different operating system, an older Linux kernel, or a recovery option on your next restart. After that reboot finishes, GRUB automatically reverts to your regular default boot entry. [1, 2, 3, 4]
  • How to Specify Entries: You can target a menu item by its number (starting at 0), its title string, or a path through submenus using a greater-than sign (>) (for example: sudo grub-reboot "Advanced options for Ubuntu>Ubuntu, with Linux 6.8.0-79-generic"). [1, 2, 3]
  • Prerequisites: It requires administrator privileges (sudo), and your system's GRUB environment block must be writable (it may not work if your / boot is on certain LVM or MDRAID configurations). [1, 2, 3]

If a headless server hangs completely during the boot phase (such as freezing at a systemd service, locking up during hardware initialization, or suffering a kernel panic), the standard grub-reboot flag won't automatically clear itself because the OS never fully reaches the state required to consume the next_entry environment variable.

To ensure the server automatically falls back to your old stable kernel if it hangs or fails to boot, you need a true watchdog fallback mechanism rather than just a one-time boot flag.

Method 1: Use GRUB's Built-in savedefault and Fallback (Recommended)

GRUB has native support for remembering the last successful boot or falling back to a secondary entry if the primary one fails. Configuring this requires updating your GRUB defaults.

1.Edit your GRUB configuration:Requires sudo.

Open the GRUB configuration file using your preferred text editor:

Bash 
sudo nano /default/grub

(Note: On some distributions, this file is located at / etc/default/grub).

2.Enable saved default booting:Update GRUB parameters.

Modify or add the following lines to track the default boot entry:

Plaintext 
GRUB_DEFAULT=saved
GRUB_SAVEDEFAULT=true

Verification: Ensure these variables are uncommented (no leading #) and saved properly in the file.

3.Update GRUB bootloader:Apply changes.

Regenerate your main configuration file so the changes take effect:

Bash 
sudo update-grub

Verification: The command completes without syntax errors, outputting that it has successfully generated the grub.cfg file.
